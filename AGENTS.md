# Repository-local GitHub instructions

These instructions apply only to work in this repository.

- Do not add tool or agent watermarks to GitHub-facing content.
- Do not state or imply that a commit, pull request, review, issue, release, or other contribution was authored by an AI agent.
- Do not add tool-generated attribution trailers or signatures to commit messages. This includes `Co-Authored-By` lines added for an agent or coding tool.
- Do not mention or promote "T3 Code" in commit messages, pull-request titles or descriptions, reviews, issue comments, release notes, tags, or other repository metadata.
- Write GitHub content as ordinary Tapline project communication. Describe the change, reason, evidence, and remaining risk without crediting the tool used to produce it.
- Preserve copyright notices, dependency licenses, attribution files, and other notices required by law or an upstream license. Required legal attribution is not a watermark.
